Testimonials Manager

Add real client reviews to the “Testimonials” section of sptranslationservices.com · Gestor de testimonios

1 · Add a review / Añadir una opinión

Paste the review email you received (“New client review — sptranslationservices.com”) and press Fill from email, or type the details yourself. For a Google review, copy the reviewer’s name and text from your Google listing and set Source to “Google review”. Only publish reviews the client agreed to publish.

This is what the site will show, in this order. Reorder or remove entries here — nothing is published until step 3.

3 · Publish / Publicar

  1. Press Copy updated file.
  2. Press Open file on GitHub and sign in as santiagopedraza01-sketch if asked.
  3. In the GitHub editor, select everything (Cmd/Ctrl + A), paste (Cmd/Ctrl + V), then press Commit changes… → Commit changes.
  4. The testimonials on the site update about a minute later.
